# Banking System - Микросервисная банковская система

## О проекте

**Banking System** - учебный проект, разработанный в рамках изучения современных подходов к проектированию и\
реализации программного обеспечения на языке Java. Система представляет собой многосервисное приложение, охватывающее\
ключевые аспекты промышленной разработки: объектно-ориентированное проектирование, автоматизированное тестирование,\
микросервисную архитектуру, построение RESTful API, обеспечение безопасности и асинхронное взаимодействие сервисов\
с использованием Apache Kafka.

Проект реализует базовую функциональность онлайн-банкинга, включая управление пользователями и банковскими счетами,\
проведение транзакций, поддержку социальных связей (дружба между пользователями) и гибкую систему расчёта комиссий\
в зависимости от типа операции.


## Архитектура

Система состоит из трёх независимых сервисов, объединённых через стандартные протоколы:

| Сервис            | Роль                                                                 |
|-------------------|----------------------------------------------------------------------|
| **Bank Service**  | Ядро бизнес-логики: управление пользователями, счетами, операциями   |
| **API Gateway**   | Точка входа: аутентификация, авторизация, маршрутизация запросов     |
| **Event Storage** | Журналирование изменений: асинхронный приём событий через Kafka      |

> Все сервисы - автономные Spring Boot приложения. Между ними нет прямых зависимостей по коду, только через HTTP и Kafka.


## Ключевые возможности

### Пользователи и социальные связи
- Профиль: логин, имя, возраст, пол, цвет волос
- Дружба: динамический список друзей (двусторонние связи)
- Роли:
    - **Client** - обычный пользователь (имеет счета, может переводить деньги)
    - **Admin** - технический аккаунт для управления системой (не имеет счетов)

### Счета и транзакции
- Каждый пользователь может иметь несколько счетов
- Все операции (пополнение, снятие, перевод) сохраняются в истории
- Гибкая система комиссий:
    - **0%** - между своими счетами
    - **3%** - другу
    - **10%** - любому другому пользователю

### Безопасность
- **Закрытая регистрация**: только администратор может создавать аккаунты
- **Role-Based Access Control**:
    - Клиенты видят и редактируют **только свои** данные
    - Администраторы имеют расширенный доступ к системе
- **Защита от несанкционированного доступа**:
    - Все эндпоинты (кроме `/login`) требуют аутентификации
    - Нарушения прав доступа → `403 Forbidden`
    - Отсутствие токена → `401 Unauthorized`
- Пароли хранятся в хэшированном виде (BCrypt)

### Асинхронное журналирование событий
- При любом изменении пользователя или счёта **Bank Service** публикует событие в Kafka:
    - `client-topic` - события пользователей
    - `account-topic` - события счетов
- **Event Storage** потребляет эти события и сохраняет в PostgreSQL
- Позволяет строить аудит или аналитику.

## Технологии

- **Язык**: Java 21
- **Сборка**: Maven
- **Фреймворки**: Spring Boot, Spring MVC, Spring Security, Spring Data JPA
- **База данных**: PostgreSQL
- **ORM**: Hibernate
- **Сообщения**: Apache Kafka
- **API**: REST, OpenAPI (Swagger UI)
- **Тестирование**: JUnit, Mockito
- **Документация**: JavaDoc + Swagger
